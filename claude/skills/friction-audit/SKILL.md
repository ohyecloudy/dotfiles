# Friction Audit

세션 기록에서 사람과 에이전트 사이의 **마찰**을 찾아 원인을 진단한다. 고치지는 않는다 - 수정은 보고서를 본 뒤 따로 진행한다.

## 경계

- **이 머신만** 본다. 세션 기록(`~/.claude/projects/`)과 보고서(`~/friction-audit/`)가 머신마다 따로라 머신 간 합산은 하지 않는다.
- 대상은 기간 안 전체 세션 중 사용자 발언 3개 이상인 것. 서브에이전트 기록과 지금 실행 중인 세션은 뺀다.
- 범주는 mattpocock `retro` 스킬의 7개(에이전트 환경)에 Emacs/사람 쪽 4개를 더한 것. 정의는 [worker.md](worker.md).

## 절차

### 1. 준비

`HOME_W`는 python이 읽을 수 있는 홈 경로. Windows Git Bash는 `HOME_W=$(cygpath -m ~)`, macOS/Linux는 `HOME_W=$HOME`. `<Temp>`도 같은 형식(`$(cygpath -m "$TEMP")` 또는 `${TMPDIR:-/tmp}`).

`PY=$(command -v python3 || command -v python)` - macOS에는 `python` 명령이 없을 수 있다. Python 3.9 이상(macOS 기본 `/usr/bin/python3`가 3.9).

```bash
"$PY" -I -X utf8 "$HOME_W/.claude/skills/friction-audit/friction_audit.py" prepare <기간> "<Temp>/friction-audit-<YYYYMMDD-HHMM>" --exclude "${CLAUDE_SESSION_ID}"
```

- `<기간>`: 인자가 있으면 그대로, 없으면 `auto`.
- `-X utf8`은 빼지 않는다. `-I`가 `PYTHONIOENCODING` 같은 환경 변수를 무시해서 Windows에서 한글 출력이 깨진다.
- 출력 `summary.json`: 기간, 세션 수, 묶음 수, 프로젝트별 수, 지난 보고서 경로.
- 세션이 0개면 그렇게 보고하고 끝낸다.

### 2. 비용 표시

기간, 세션 수, 서브에이전트 수(= 묶음 수)를 한 줄로 알린다.

- 묶음이 **25개 이하**면 묻지 않고 진행한다.
- 25개를 넘으면 진행할지 묻는다. 선택지에 "최근 N일로 줄이기"를 같이 보여준다(N은 묶음이 25개 안에 들어오는 대략의 일수).

### 3. 알려진 패턴 (지난 보고서가 있을 때)

`summary.json`의 `previous_report`를 Read해 다음을 뽑는다.

- 알려진 패턴: `* 발견 항목` 아래 `**` heading 제목, `* 1회성 항목` bullet
- 지난 권고: `* 권고` 아래 `** TODO`/`** DONE` heading 전체 (본문 포함). 이월과 효과 비교에 쓴다

### 4. 세션 분석 (서브에이전트)

`batches.json`의 묶음마다 Agent 도구로 `general-purpose` 서브에이전트를 **병렬**로 띄운다. 프롬프트:

- [worker.md](worker.md) 절대 경로 (이 절차를 따르라고 지시)
- 묶음의 세션 디렉터리 절대 경로 목록 (`<out>/sessions/<id8>/`)
- `signals.jsonl` 절대 경로
- 알려진 패턴 목록 (있으면)

결과는 도착하는 대로 `<out>/results/<묶음 번호>.md`에 Write로 저장한다 - 컨텍스트가 compact돼도 잃지 않게.

### 5. 병합

- 같은 마찰을 세션 간에 합친다. 빈도 = 마찰이 나온 세션 수 / 전체 세션 수.
  - 기계적으로 셀 수 있는 신호(E1 붙여넣기, 도구 오류, 거부, 중단, 반복 짧은 발언)는 `signals.jsonl`과 `summary.json`의 값을 쓴다. worker 보고를 합친 근사치면 "약"을 붙인다.
- 세션 2개 이상 -> `* 발견 항목`, 1개 -> `* 1회성 항목`. 단, 비용이 `보안`이면 1개여도 발견 항목.
- 심각도 = 빈도 x 비용. 비용 순서: 보안 > 재작업 > 흐름 끊김 > 사람 시간 > 토큰.
- 지난 보고서가 있으면 항목마다 `신규` / `지속`을 정한다. 지난 1회성 항목이 다시 나오면 발견 항목으로 올리고 `지속`.
- worker의 제안을 모아 항목마다 대안을 정리하고 추천을 고른다. 추천 기준: 효과가 크고 비용이 작은 것, 같은 마찰을 여러 개 줄이는 것.
- worker의 판정을 그대로 믿지 않는다. 보고서에 "확인한 사실"로 적을 것은 직접 확인한다(설정 파일, 스킬, agent-shell 소스 grep).

### 6. 공부 추천

`* 권고`와 `:지속:` 발견 항목에 연결되는 것만 3-5개 고른다.

- 우선순위: Emacs 기능/패키지 -> Claude Code 기능(hooks, MCP, settings) -> 셸/OS 지식
- OS: 회사 Windows, 집 macOS. 공통 주제를 우선하고, OS 전용이면 다른 OS의 대응 방법도 함께 적는다.
- 이미 쓰는 것은 빼거나 "더 깊게"로 표시한다. dotfiles `doom.d/init.el`, `doom.d/packages.el`, `doom.d/config.org`를 grep해 확인한다.
- 숙련도는 `~/.claude/CLAUDE.local.md`를 보고 시작점을 고른다. 낮으면 입문 문서.
- 외부 패키지를 추천할 때만 WebSearch(standard)로 지금도 유지되는지 확인한다.
- 마찰 하나와 연결되지 않는 일반 추천("Emacs Lisp를 공부하세요")은 쓰지 않는다.

### 7. 보고서 작성

`~/friction-audit/YYYY-MM-DD-HHMM.org`에 쓴다. 디렉터리가 없으면 만든다. 커밋하지 않는다. 형식은 아래 [템플릿](#템플릿).

- 권고: 심각도 상위 5개 발견 항목의 **추천 대안**을 `** TODO`로 올린다. 보안 항목은 순위와 무관하게 추가한다.
- 이월: 지난 보고서의 `** TODO` 권고를 모두 `:이월:` 태그로 복사한다.
  - 이번 상위 5개와 같은 마찰이면 heading 하나로 합치고 `:이월:`만 붙인다.
  - 이번 빈도가 0이어도 이월한다. 판정은 "해소 추정"으로 적고 DONE 처리는 사용자가 한다.
  - 지난 보고서에서 `DONE`인 권고는 이월하지 않는다.
- 지난 권고 결과: 지난 보고서에서 `DONE`인 권고만, 효과를 비교한다.

### 8. 포매팅

- 본문은 [org-writing.md](../shared/org-writing.md) 규칙.
- [org-formatting.md](../shared/org-formatting.md)의 정렬을 돌린다. Windows Git Bash에서는 경로를 `cygpath -m`으로 넘기고 `</dev/null`을 붙인다(없으면 batch emacs가 입력을 기다리며 멈출 수 있다).
- heading 링크 `[[*heading][...]]`가 모두 실제 heading을 가리키는지 [reading-doc.md](../shared/reading-doc.md) "포매팅"의 검사로 확인한다.

## 형식 규칙

- 섹션 순서는 템플릿 그대로. 항목이 없는 섹션은 heading 아래 `- 없음`. 단 지난 보고서가 없으면 `* 지난 권고 결과`를 생략한다.
- heading에 내용 없는 꼬리(`- 상위 5개` 등)를 붙이지 않는다.
- 태그
  - 발견 항목: 고칠 곳 + `신규`/`지속`만. 범주는 본문 첫 bullet
  - 고칠 곳 값의 `-`는 org 태그에 못 쓰므로 `_`로 (`agent_shell`, `claude_config`, `emacs_mcp`, `repo_check`)
- 제안
  - 방법이 하나면 `*** 제안 - <고칠 곳>: <무엇을>`
  - 여럿이면 `*** 제안 - 추천: <대안 이름>` 아래 대안마다 `****`. 추천을 맨 앞에. 대안은 짧은 이름으로 부르고 A/B 같은 문자 라벨은 쓰지 않는다
  - 대안의 효과에는 **해결되지 않는 것**도 적는다
- 사례는 `*** 사례` heading 아래 최대 3개. 비밀값은 `...`로 가린다.
- 지난 권고 판정 문구는 3개로 고정: "해소 추정"(이번 0), "줄었지만 남음", "변화 없음". DONE인데 변화 없음이면 `확인 필요:`를 앞에 붙인다.
- 코드/파일 위치는 절대 경로. Windows는 `C:/...` 형식.
